# 📚 課表 Widget 產生器

用瀏覽器排課表，一鍵產生可以放在 iPhone / iPad 桌面的 [Scriptable](https://scriptable.app/) 小工具腳本。

**線上使用：** https://berton0310.github.io/timetable-widget/

純前端、單一 HTML 檔，沒有後端也沒有任何外部相依，資料只存在你自己瀏覽器的 localStorage。

---

## 功能

### 像排課表一樣編輯
主畫面就是一張週課表格線：

| 操作 | 效果 |
| --- | --- |
| 點空格 | 新增課程 |
| 在空格上下拖曳 | 一次選好幾節再新增 |
| 拖曳課程方塊 | 搬到別天／別時段 |
| 拉方塊下緣 | 調整這門課上幾節 |
| 點方塊 | 編輯或刪除 |

撞課會自動框紅並在上方提示。

### 外觀
- 8 種配色主題（暗夜、深海、森林、莓果、暮色、純黑、紙白、奶油）
- 低調上色（只有上課中才亮）／繽紛上色（每堂用自己的顏色）
- 課程列裝飾：左側線條／圓點／色塊卡片／無
- 時間顯示：「第 5 節」或「13:10」
- 可選擇是否顯示老師、必選修、「上課中」標籤

所有選項都用**真的迷你 Widget 縮圖**呈現，不用讀文字猜差別。

### 即時預覽
小 / 中 / 大 / 超大四種尺寸的等比例模擬，可以「假裝現在是星期幾、第幾節」來檢查高亮效果。

### 上課提醒
可產生本機通知排程（提前 N 分鐘、一次排未來幾天、可只提醒每天第一堂）。

> ⚠️ Widget 的更新時機由 iOS 決定，不保證每天觸發。想讓提醒穩定，請在
> 「捷徑 App → 自動化 → 個人自動化 → 時間」設一個每天早上執行這支腳本的排程
> （動作選 Scriptable 的 Run Script）。iOS 每個 App 待處理通知上限 64 則，本腳本最多排 50 則。

### 其他
- 節數 1～14 節、每節開始時間與長度都可調
- 可匯入舊腳本（貼上或選 .js 檔），自動讀回課程與外觀設定
- 產生 → 匯入 → 再產生的結果完全一致

## 怎麼裝到手機上

1. 在網頁按「下載到手機」拿到 `.js` 檔。
2. 手機開 **Scriptable** App，把檔案放進「iCloud Drive → Scriptable」資料夾，
   或在 App 裡新增腳本後貼上程式碼。
3. 長按桌面 → 加入小工具 → Scriptable → 選尺寸。
4. 編輯小工具 → Script 選這支 → When Interacting 設 Run Script。
5. 有開提醒的話：先在 Scriptable 手動跑一次允許通知權限，再依上面的說明設捷徑自動化。

## 本機執行

不需要建置工具，直接用瀏覽器開啟 `index.html` 即可。
