⚠️ Widget 什麼時候更新是 iOS 決定的，不保證每天跑到。 想讓提醒穩定，請在「捷徑 App → 自動化 → 個人自動化 → 時間」設一個每天早上執行這支腳本的排程 （動作選 Scriptable 的 Run Script）。iOS 每個 App 待處理通知上限 64 則，本腳本最多排 50 則。

⬇ 拿到手機上

1. 按下面的「下載到手機」拿到 .js 檔。
2. 手機開 Scriptable App，把檔案放進「iCloud Drive → Scriptable」資料夾，
　 或在 App 裡新增腳本後貼上程式碼。
3. 長按桌面 → 加入小工具 → Scriptable → 選尺寸。
4. 編輯小工具 → Script 選這支 → When Interacting 設 Run Script。
5. 有開提醒的話：先在 Scriptable 手動跑一次允許通知，再到「捷徑 → 自動化 → 　 個人自動化 → 時間」設每天早上執行 Run Script（關掉「執行前先詢問」）。
